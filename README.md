Reflection on Development Process and Learning Outcomes

During the development of the REST Countries API project, I followed a step-by-step approach to ensure the application was both functional and easy to maintain. I began by building the basic HTML structure and layout based on the provided designs, then added CSS using a mobile-first approach. Once the layout was stable, I focused on JavaScript to fetch and display country data from the REST Countries API. This order helped me clearly separate structure, style, and behavior.

One of the main challenges I faced was working with external APIs. At first, the countries and flags did not display as expected due to changes in the API response. I resolved this issue by requesting only the required fields from the API and adding proper error handling. This experience taught me the importance of reading API documentation carefully and writing defensive code that can handle unexpected failures.

Another challenge was implementing search, region filtering, and dark mode in a clean and readable way. I solved this by storing the fetched data in a global variable and reusing it for filtering and rendering. For dark mode, I used CSS variables and a class toggle, which kept the styling simple and scalable.

If I had more time, I would improve this project by adding a detailed country page with border navigation, saving the theme preference using localStorage, and enhancing accessibility. Overall, this project strengthened my understanding of API integration, responsive design, and real-world frontend development workflows.
